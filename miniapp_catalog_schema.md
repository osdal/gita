# Схема каталога для будущего Telegram Mini App

Приложение пока не реализуется. Документ фиксирует модель данных и согласованные словари.

Сейчас каталог содержит 318 произведений и одну связанную запись типа `title_alias`.

## Запись произведения

| Поле | Тип | Примечание |
|---|---|---|
| `work_id` | string | Стабильный ключ исходной последовательности; после объединения одного дубля есть пропуск `ggg-0231`. |
| `title` | string | Исходное заглавие из каталога. |
| `title_normalized` | string | Поисковая форма, вычисляемая из заглавия; уже добавлена. |
| `aliases` | string[] | Подтверждённые варианты заглавия/транслитерации; одна запись уже содержит подтверждённый вариант. |
| `section_code`, `section` | string | Раздел сборника. |
| `subsection_code`, `subsection` | string/null | Подраздел сборника. |
| `author` | string | Автор или оговорённая атрибуция. |
| `author_type` | enum | Тип авторства/атрибуции из словаря ниже. |
| `author_source`, `author_status` | string | Основание и редакционный статус атрибуции. |
| `language` | string[] | Нормализовать для API в ISO 639-3: бенгали `ben`, санскрит `san`, хинди `hin`, ория `ori`; смешанный язык — несколько кодов. CSV сохраняет русские подписи. |
| `language_source`, `language_status` | string | Основание языковой классификации. |
| `theme` | enum | Одна из 11 тем в `catalog_fields.md`. |
| `genre` | enum | Одна из 12 форм в `catalog_fields.md`. |
| `topic_tags` | string[] | Ноль или более дополнительных меток; в CSV значения разделены `;`. |
| `ritual_time` | enum/null | `morning`, `day`, `evening`, `special` либо null. |
| `printed_page` | integer/string | Печатная пагинация. |
| `matched_pdf_page` | integer/null | Страница PDF, если известна. |
| `text` | string/null | OCR-черновики находятся в `text_extraction_manifest.csv` для 318 произведений. Текстовые границы и продолжения подлежат сверке. |
| `classification_status` | string | Общее состояние классификации. |

## Словарь авторства

Текущие редакторские значения различают: персональный автор; источник-писание; источник-писание/повествователь; традиционная атрибуция; народная/традиционная песня; традиционный литургический текст без установленного индивидуального составителя; автор не установлен; несколько авторов/строф разных авторов; смешанные традиция и источник. Для API позднее можно завести машинные коды, сохранив подписи для показа.

## Поиск и фильтры

Полнотекстовый поиск: заглавие, подтверждённые варианты, текст и авторская строка. Фильтры: тема, жанр, язык, автор/тип атрибуции, метки, контекст исполнения. Сортировки: порядок сборника (`printed_page`), заглавие, автор. Ссылки используют `work_id`, а не позицию строки. Записи `title_alias` индексируются в поиске, но не отображаются как самостоятельные произведения.

## Подготовка текста

Строка `title_alias` использует `alias_id` и `parent_work_id` и не получает отдельный `work_id`. Текст хранится отдельно от каталога или как поле связанной записи по `work_id`. Каждый текст должен иметь `text_status`, `text_scope`, `ocr_confidence` и источник/страницы. Нынешние OCR-черновики могут содержать только фрагмент страницы; не публиковать их как проверенную транскрипцию.
