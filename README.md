# Telegram Mini App песенника

Мини-приложение использует существующий каталог и OCR-черновики без изменения исходных CSV. Каталог содержит 318 произведений. Поиск работает по заглавию, вариантам названия, автору и тексту; фильтры — по теме, автору, жанру и языку. Варианты заглавий ведут к основной записи. Неустановленное авторство показывается как «Автор не установлен», OCR-тексты снабжены пометкой черновика.

## Локальный запуск

Требуется Python 3.10 или новее, дополнительных пакетов нет.

```powershell
$secure = Read-Host "Пароль админки (не менее 12 символов)" -AsSecureString
$secretPtr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
try {
    $env:ADMIN_PASSWORD = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($secretPtr)
    python server.py
}
finally {
    $env:ADMIN_PASSWORD = $null
    [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($secretPtr)
}
```

Откройте `http://127.0.0.1:8100`. Нажмите «Вход в админку» и введите пароль, заданный в `ADMIN_PASSWORD`. Откройте PowerShell локально на компьютере, где работает сервер; пароль не хранится в файлах проекта. Сессия действует 12 часов и сбрасывается при перезапуске сервера.

Первый запуск создаст `app_state.json` с исходными ролями, разрешениями, страницей «О сборнике» и настройками баннеров. Этот файл хранит назначения ролей, страницы, баннеры и редакторские переопределения; включите его в резервные копии. Порт можно поменять переменной окружения `PORT`.

## Размещение на Oracle Cloud

Целевой сервер: Oracle Cloud Free, Ubuntu 24.04. Приложение должно работать отдельной службой и слушать только локальный порт за уже установленным Caddy. База данных и административные настройки будут храниться на сервере, вне публичного Git-репозитория. Перед публикацией необходимо перенести каталог и тексты в базу, исключить исходный PDF/OCR-данные и подготовить чистую Git-историю: исходный коммит содержит эти файлы.

Для Telegram Mini App потребуется HTTPS-домен, направленный на сервер. Не храните пароли, токены бота и дамп базы в Git.
## Подключение к Telegram

Telegram Mini App должен открываться по публичному HTTPS URL. Разместите сервер за HTTPS reverse proxy, задайте `APP_HOST=127.0.0.1`, `PORT=8100`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID` и `ADMIN_PASSWORD`, затем укажите URL в настройке Mini App у BotFather. Не публикуйте токен бота или пароль и не добавляйте их в репозиторий. Сервер проверяет подпись и срок действия Telegram `initData`; для компьютера предусмотрен отдельный вход по паролю администратора.

## Администрирование

- Только владелец может создавать роли, менять определение разрешений и назначать доступ пользователям по Telegram ID.
- Владелец задаётся переменной `TELEGRAM_OWNER_ID`; роль владельца зарезервирована и не передаётся другим пользователям.
- Можно создавать любое число ролей и настраивать каждой разрешения: чтение/правка контента, управление отдельными страницами и управление баннерами. Эти действия задаются самим приложением; чтобы добавить новый тип действий, потребуется доработка кода.
- Баннеры можно показывать глобально или на выбранной странице. Отдельные страницы, публикация и баннеры редактируются в админке.
- Исправления названия, автора и текста сохраняются как переопределения в `app_state.json`; исходные CSV остаются нетронутыми.

## Текущая граница прототипа

Это автономный MVP для одного процесса Python. Перед публичной эксплуатацией следует разместить его за HTTPS reverse proxy и настроить резервное копирование каталога. Данные административной конфигурации хранятся в JSON-файле без многопользовательских транзакций; для растущей нагрузки конфигурацию и аудит изменений разумно перенести в базу данных.
